# tracegap Implementation Plan

> Execute inline with executing-plans. The user authorized autonomous selection,
> development, testing and public GitHub publication; no design approval is needed.

**Goal:** Ship an offline GPU trace activity/gap analysis CLI.
**Architecture:** Strict trace reader -> rational interval sweep -> text/JSON CLI.
**Tech stack:** Python >=3.10, standard library, unittest, setuptools, GitHub Actions.
**Spec:** ../specs/2026-11-03-tracegap-design.md

## Global constraints

- Python >=3.10, zero runtime dependencies, MIT, version 0.1.0.
- Read-only local analysis; no model execution or bottleneck-cause inference.
- Downloads, environments and temporary artifacts under E:\codex\download.
- Use only this new repository, without changing existing repositories.

## Task 1: Read trace activities

Files: `tracegap/reader.py`, `tests/test_reader.py`, `tests/helpers.py`.
Produces typed `Trace`/`Activity` values with exact microsecond offsets.

- [x] Write fixtures/tests first: an event at ts=1000,dur=4000 has a 4000-us
  envelope; CPU events do not enlarge it; decimals retain their exact offsets.
- [x] Run `python -m unittest tests.test_reader -v` and observe missing reader.
- [x] Implement JSON/gzip loading, classification and validation.
- [x] Run the reader suite and commit after the diff is reviewed.

## Task 2: Compute activity, concurrency and gaps

Files: `tracegap/analysis.py`, `tests/test_analysis.py`.
Consumes `Trace`; produces a JSON-compatible report dictionary.

- [x] Write tests first: [0,4], [2,6], [8,10] ms yields busy=8, sum=10,
  concurrent=2, idle=2, longest gap=[6,8] and peak concurrency=2.
- [x] Run `python -m unittest tests.test_analysis -v` and observe missing analysis.
- [x] Implement clipping, endpoint aggregation, device groups and ranked output.
- [x] Compare interval sets with an independent discrete oracle; run suites,
